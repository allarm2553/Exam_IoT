🛡️ มาตรฐานความปลอดภัย 6 ชั้น (6-Layer Anti-Cheat)

ระบบทั้งสองชุดมาพร้อมกลไกตรวจจับและป้องกันการทุจริตที่ทำงานพร้อมกันทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

🔀
1. Randomizer
สลับโจทย์และตัวเลือกทุกครั้ง ไม่แสดงเลขข้อ ป้องกันการจำลำดับ
🔒
2. Single Submission
ตรวจสอบรหัสนักเรียนแบบเรียลไทม์ ส่งคำตอบได้เพียงครั้งเดียว
🚫
3. Anti-Screenshot
ดักจับ PrintScreen, บล็อก Ctrl+P/S, Snipping Tool, ล้างคลิปบอร์ดทันที
📱
4. Mobile Guard
บล็อกท่าทางปัด 3 นิ้วแคปจอ และปิดเมนูกดค้าง (Callout) บน iOS/Android
⬛
5. Blur Shield
ม่านดำบังหน้าจอทันทีเมื่อหลุดโฟกัส ล็อกข้อสอบหากสลับแอปเกิน 3 ครั้ง
💧
6. Dynamic Watermark
ประทับลายน้ำระบุ "รหัส • ชื่อ" ทแยงมุมทั่วหน้าจอแบบโปร่งแสง

👨‍🏫 จัดการระบบสอบสำหรับครูผู้สอน

แบบทดสอบ: การใช้งาน Wi-Fi บน ESP32
สถานะ: ยังไม่ได้ระบุ Google Sheets ↗️ เปิดชีตของคุณ 
// กำลังโหลด Code.gs...
// กำลังโหลด Index.html...

🚀 วิธีนำไปเปิดใช้งานบน Google Apps Script Web App:

  1. สร้าง Google Sheets เปล่า 1 ไฟล์บน Google Drive ของคุณ
  2. คัดลอก URL ของ Google Sheets มาวางในช่องด้านบน แล้วกดปุ่ม "💾 เซฟลิงก์"
  3. ใน Google Sheets ไปที่เมนู ส่วนขยาย (Extensions) > Apps Script
  4. กดปุ่ม "📋 คัดลอก Code.gs (ที่ใส่ Sheet ID แล้ว)" แล้วนำไปวางทับในไฟล์ Code.gs
  5. ใน Apps Script Editor กดเครื่องหมาย + ด้านซ้าย เลือก HTML ตั้งชื่อว่า Index (ตัว I พิมพ์ใหญ่)
  6. กดปุ่ม "📄 คัดลอก Index.html" แล้วนำไปวางทับในไฟล์ Index.html
  7. กดปุ่ม ทำให้ใช้งานได้ (Deploy) > การทำให้ใช้งานได้ใหม่ (New deployment) เลือกประเภท Web app
  8. ตั้งค่า Execute as: ฉัน (Me) และ Who has access: ทุกคน (Anyone) จากนั้นกด Deploy เพื่อรับลิงก์ส่งให้นักเรียนเข้าสอบได้ทันที!
